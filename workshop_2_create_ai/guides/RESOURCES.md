## 🎨 Image Generation

- **[Hugging Face Diffusion Models Course](https://huggingface.co/learn/diffusion-course/unit0/1)** — Free, in-depth course on how diffusion models work.
- **[Stable Diffusion Web UI (AUTOMATIC1111)](https://github.com/AUTOMATIC1111/stable-diffusion-webui)** — Run Stable Diffusion locally with a GUI.
- **[CLIP Interrogator](https://huggingface.co/spaces/pharma/CLIP-Interrogator)** — Analyze an image to reverse-engineer the prompt that could create it.
- **Book**: *"Build a Text-to-Image Generator (from Scratch)"* by Mark Liu — Deep dive into Transformer-based image generation.

## 🖥️ Running Local Models

- **[Ollama](https://ollama.com/)** — The easiest way to run local LLMs. One-command install.
- **[Ollama GitHub](https://github.com/ollama/ollama)** — Source code, examples, API documentation.
- **[LM Studio](https://lmstudio.ai/)** — GUI alternative to Ollama for running local models.
- **[Open WebUI](https://github.com/open-webui/open-webui)** — ChatGPT-like interface for any local model.
